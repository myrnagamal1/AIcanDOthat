Version Control

Host Your Project on GitHub

GitHub lets your team store code, collaborate, and share what you've built — all in one place. Here's how to get started.

1️⃣

Create a Repository

Go to github.com → click New Repository. Give it a name, set it to Private (for internal work) or Public. Hit Create.

2️⃣

Push Your Files

In your terminal, run:
git init → git add . → git commit -m "first" → git push
Or drag & drop files directly in the GitHub web UI.

3️⃣

Enable GitHub Pages

Settings → Pages → set Source to main branch. Your site goes live at yourusername.github.io/repo-name — perfect for HTML presentations like this one!

💡

SAP GitHub Access

Use your SAP GitHub Enterprise account at github.tools.sap for internal projects. Your I-number login works. Ask your manager for org access if needed.

🚀
Pro tip: use Claude Code to generate your README Ask Claude: "Write a README for my project that explains what it does and how to run it." Then paste it into a README.md file at the root of your repo.
